# ปฏิทินไทย พ.ศ. 2569 / ค.ศ. 2026

เว็บไซต์ปฏิทินแบบ static สำหรับ GitHub Pages รองรับมือถือและ PWA/offline cache

## ไฟล์
- `index.html` หน้าเว็บไซต์
- `calendar-data.js` ข้อมูลวันสำคัญ/วันหยุด/จันทรคติที่ฝังไว้
- `manifest.webmanifest` ข้อมูลติดตั้งเป็นแอป
- `sw.js` Service Worker สำหรับแคชเพื่อเปิดออฟไลน์
- `icons/` ไอคอน PWA

## ติดตั้งบน GitHub Pages
1. สร้าง Repository ใหม่ เช่น `thai-calendar-2569`
2. แตก ZIP แล้วอัปโหลด **ไฟล์และโฟลเดอร์ภายใน** ไปไว้ที่ root ของ repository (ต้องเห็น `index.html` ในหน้าแรก)
3. ไปที่ **Settings → Pages**
4. ใน **Build and deployment** เลือก **Deploy from a branch**, branch `main`, folder `/(root)` แล้ว Save
5. รอ workflow เผยแพร่ แล้วเปิด URL ที่ GitHub Pages แสดง
6. เปิดเว็บขณะออนไลน์อย่างน้อยหนึ่งครั้งเพื่อให้ Service Worker แคชไฟล์ จากนั้นจึงทดสอบออฟไลน์
7. บน Android ใช้เมนูเบราว์เซอร์ **เพิ่มไปยังหน้าจอหลัก / Install app**

## หมายเหตุด้านความถูกต้อง
ชุดข้อมูลเริ่มต้นเป็นตัวอย่างใช้งานและยังไม่ควรถือเป็นปฏิทินราชการ/จันทรคติที่ตรวจสอบครบถ้วน วันหยุดบางรายการอาจเป็นวันหยุดธนาคารหรือวันหยุดเฉพาะหน่วยงาน และวันพระ/วันขึ้นแรมบางวันเป็นค่าประมาณอ้างอิง โปรดตรวจสอบกับประกาศสำนักเลขาธิการคณะรัฐมนตรี และแหล่งปฏิทินไทยที่เชื่อถือได้ก่อนใช้จริง ควรปรับข้อมูล `calendar-data.js` หลังตรวจสอบวันที่ทั้งหมด

## การตรวจสอบ
- `index.html` ใช้ JavaScript และ CSS ในเครื่อง ไม่เรียก API ภายนอก
- Service Worker ต้องใช้ HTTPS หรือ localhost; GitHub Pages รองรับ HTTPS
- การเปิดออฟไลน์ใช้ได้หลังโหลดเว็บออนไลน์ครั้งแรกและแคชสำเร็จ
